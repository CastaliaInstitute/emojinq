- License status: collection listing indicates a Creator Pro download; exact production terms are not verified here
- Use decision: anatomy, pose, clothing, and prop orientation reference only; do not ship, trace, or redistribute the downloaded source without explicit license approval

For the neutral standing-person card, the most relevant comparison reference is
[standing person 5630034](https://thenounproject.com/icon/standing-person-5630034/)
from the Human Figures - Outline set by Juicy Fish. The reference confirms the
required isolated, full-body read, but its generic pictogram treatment is not a
production target by itself; the Castalia version must add natural gesture,
weight-bearing feet, and a restrained sumi-e stroke hierarchy.

Production people remain Castalia-authored SVG brush studies. Each production file
must retain its own `data-reference-source`, `data-reference-role`, and
`data-license-status` attributes.
